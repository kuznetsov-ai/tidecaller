# Солевязь (SALTBOUND)

Браузерный рогалит-декбилдер. Игрок и враг делят одну шкалу прилива: карты отлива, штиля и паводка сильнее только в своей воде, а в конце хода вода сама поднимается. Три акта, три мастера, верфь между рейсами.

Прототип для заявки в RND GamesUp42. Игра открывается по ссылке, без установки и регистрации. Сохранение лежит в `localStorage`.

## Как запустить

Нужны Node.js 22+ и npm.

```bash
npm install
npm run dev
```

Игра откроется на `http://127.0.0.1:4317`.

Сборка для любого статического сервера (её и нужно класть за Caddy):

```bash
npm run build
```

Результат — папка **`public_site/`**: `index.html`, `onepager.html` и `assets/`. Имена `dist`, `build` и `out` не используются.

Отдать папку как есть:

```bash
cd public_site
python3 -m http.server 4317
```

`index.html` как файл с диска не открывается: это модули, нужен сервер. Страница о игре — `onepager.html`, ссылка на неё есть в главном меню.

Проверки:

```bash
npm run check    # правила, карта, учебная бухта, один полный заход
npm run sim      # 40 партий жадной политики: глубина, победы, оценка минут
npx playwright test
```

## Стек

TypeScript, React, Vite. Сборка — статические файлы, `base` относительный, чтобы страница жила в любом каталоге. Шрифты Literata и Manrope вшиты в бандл (латиница и кириллица), внешних запросов в рантайме нет. Звук — WebAudio, без файлов. Картинки существ и узлов — SVG в коде.

Логика партии не зависит от React: `src/game` можно гонять из `tsx` без браузера. Экран только рисует состояние и шлёт действия.

## Что сделал AI и что задал человек

Человек поставил задачу: браузерный прототип под критерии GamesUp42, не меньше получаса содержания, рогалит с собственным крюком, русский ванпейджер и честный журнал AI, статический хостинг.

Дальше решения принимал агент в Cursor (модель Grok):

- крюк «общий прилив» и три мастера, которые тянут воду в разные стороны;
- состав актов, боссов, карт и чисел;
- интерфейс, тексты на двух языках, звук, обучение, верфь;
- прогон баланса скриптом и правка после него;
- проверка первого акта в Playwright.

Человек не расставлял числа карт и не правил вёрстку руками. Если развивать игру дальше, это как раз место, где нужен человек: вкус боссов, выкидывание лишних карт и разговор с игроками, которые видят прототип впервые.

Инструмент один: агент Cursor. Отдельных генераторов картинок и внешних API нет — рисунок процедурный, чтобы стиль не расползался.
